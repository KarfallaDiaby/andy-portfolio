# Portfolio d'Andy — règles du projet

Site portfolio d'Alim Aliue Andy, réalisateur de clips et de films (Guinée → international).
Le cahier des charges complet est dans `PROMPT_CLAUDE_CODE.md`.

## Stack
Next.js 16 (App Router, `src/`), TypeScript, Tailwind CSS v4. Commandes : `npm run dev`, `npm run build`, `npm run lint`.

## Règles de marque (ne jamais enfreindre)
- Philosophie : « Less, but better. Chaque détail a un objectif. »
- Couleurs : noir, blanc, deux gris, rouge signal `#F50311`. Le rouge n'est jamais un fond.
- Titres de clips en GT Sectra Light Italic ; texte en GT America ; données en GT America Mono capitales.
- Les 5 signes : fenêtre 2.39, point rouge, titre Sectra Light Italic, ligne de données mono, grain + repères de cadrage.
- Logo : toujours le SVG de `public/brand/logo/`, jamais retapé, jamais déformé ni recoloré. Blanc sur fond sombre, noir sur fond clair.
- « The Andy Production » n'existe plus : ne jamais l'écrire.
- Coulisses en noir et blanc ; images de film toujours avec leur étalonnage.
- Ne jamais inventer de clients, récompenses ou chiffres : texte d'attente entre crochets.
